# SkillBridge – Skill Learning & Career Development Platform

## About the Project
SkillBridge is a full-stack web application designed to help users explore courses, enroll in learning programs, track their progress, and improve their skills.

## Features
- User Registration and Login
- Course Search and Filtering
- Course Enrollment
- Learning Progress Tracking
- Interactive Quiz and Score Tracking
- Responsive User Interface
- Backend API using Node.js and Express.js

## Technologies Used
- **Frontend:** HTML, CSS, JavaScript
- **Backend:** Node.js, Express.js
- **Authentication:** bcrypt and JWT
- **Data Storage:** JSON file-based storage

## Installation and Setup

1. Clone the repository:
   ```bash
   git clone YOUR_REPOSITORY_URL
   ```

2. Open the project folder:
   ```bash
   cd SkillBridge
   ```

3. Install dependencies:
   ```bash
   npm install
   ```

4. Start the application:
   ```bash
   npm start
   ```

5. Open your browser and visit:
   `http://localhost:3000`
